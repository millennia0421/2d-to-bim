# 2D→BIM 대시보드 (테스트 모드 v0.1)

평면도 이미지(PNG/JPG)를 올리면 벽을 자동 인식하고, 축척을 보정한 뒤, 3D BIM 모델을 만들어 IFC4 / JSON으로 내보내는 웹 대시보드입니다.
빌드 과정과 서버 DB가 필요 없는 정적 웹앱입니다.

## 실행

**방법 A: 로컬 서버 (권장, '샘플 도면' 버튼 사용 가능)**

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1 -Port 8080
```

브라우저에서 http://localhost:8080 을 엽니다.

**방법 B: 파일 직접 열기**: `index.html`을 더블클릭합니다. 이 방법에서는 '샘플 도면' 버튼이 동작하지 않으므로 [+ 새 변환]으로 파일을 직접 고르세요.

> 3D 라이브러리(Three.js)와 OCR 라이브러리(Tesseract.js, 한국어 데이터 포함)를 CDN에서 불러오므로 인터넷 연결이 필요합니다. OCR 한국어 데이터는 처음 한 번만 내려받고 브라우저에 캐시됩니다.

**배포**: 폴더 전체를 정적 호스팅(사내 웹서버, GitHub Pages 등)에 올리면 됩니다.

## 사용 순서

1. **대시보드**에서 `+ 새 변환`을 누르거나 이미지를 끌어다 놓습니다. 그러면 프로젝트가 생성되고 벽·문·창이 자동으로 인식됩니다.
2. **② 벽·문·창 인식**: 결과가 마음에 들지 않으면 슬라이더(임계값, 얇은 선 제거 반경, 격자 크기)를 조정합니다.
   - 문·창을 클릭하면 `문 / 창` 버튼으로 종류를 바꾸거나 삭제할 수 있습니다.
   - 실(방)도 자동으로 나뉩니다. 이어서 **도면의 실 이름을 OCR로 읽어 자동으로 붙입니다**(백그라운드, 약 10초, 진행률 표시).
   - 이름이 틀리면 실을 클릭한 뒤 이름 버튼(거실·침실·욕실 등)을 누르거나 직접 입력합니다. 직접 입력한 이름은 다시 인식하거나 OCR을 다시 실행해도 유지됩니다.
3. **③ 축척 보정**: 아래 두 방법 중 하나를 씁니다.
   - 건물 전체 폭(예: `11.6`)을 입력합니다.
   - `두 점 찍기 시작` → 도면의 치수선 양 끝을 클릭 → 실제 길이를 입력합니다.
4. **2D 편집**: 다음 조작을 하면 3D에 즉시 반영됩니다.
   - 벽 클릭: 선택(길이·두께·높이 수정)
   - `Delete`: 선택한 벽 삭제
   - `Shift+드래그`: 벽 추가
   - `Esc`: 선택이나 보정 취소
5. **⑤ 내보내기**: `IFC4 다운로드` 또는 `BIM JSON 다운로드`를 누릅니다.

프로젝트와 작업 기록은 브라우저의 localStorage에 자동 저장됩니다. 다른 PC나 브라우저와는 공유되지 않습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `css/style.css` | 대시보드 셸, 라이트/다크 테마 |
| `js/router.js` | 해시 라우팅 (`#/home`, `#/project/{id}`, `#/settings`) |
| `js/store.js` | 프로젝트 CRUD, localStorage 저장, 활동 로그 |
| `js/home.js` | 대시보드 홈(KPI, 프로젝트 목록, 최근 활동), 설정 화면 |
| `js/workspace.js` | 작업공간(스텝퍼, KPI, 속성 패널, 단계 진행) |
| `js/detect.js` | 벽 인식(이진화 → 모폴로지 열기 → 격자 → 사각형 병합), 바닥 영역 계산 |
| `js/openings.js` | 문·창 인식(벽 사이 틈 → 평행선=창, 문짝 선+1/4 원호=문) |
| `js/rooms.js` | 실 인식(벽·문·창·설비로 막힌 연결 영역 분할, 면적, 이름표 위치) |
| `js/ocr.js` | 실 이름 OCR(Tesseract.js 한국어, 전체+실별 읽기, 실 이름 사전·자모 유사도 보정, 위치로 실 배정) |
| `js/bim.js` | px 사각형 → BIM 모델(m) 변환, 통계 |
| `js/calibrate.js` | 축척 보정 계산 |
| `js/view2d.js` / `js/view3d.js` | 2D 오버레이·편집 / Three.js 3D 뷰 |
| `js/export.js` | IFC4(STEP) 생성, JSON 내보내기 |
| `serve.ps1` | Node/Python 없이 쓰는 PowerShell 로컬 서버 |

## 알려진 제한 (테스트 모드)

- 직교(수평/수직) 벽만 인식합니다.
- 문·창 높이는 고정값입니다(문 2.1m, 창대 0.9m, 창 상단 2.1m).
- 미닫이문·중문처럼 평행선으로 그려진 문은 창으로 인식됩니다. 이런 경우 `문` 버튼으로 바꿔 주세요.
- 실 이름 OCR은 사전에 있는 이름(거실, 침실, 욕실, 현관, 드레스룸 등 22종)만 붙입니다. 번호가 빠질 수 있습니다(예: 욕실1 → 욕실).
- 문 없이 트인 공간(예: 거실+주방+복도)은 하나의 실로 묶입니다.
- 치수 OCR, 다층 도면은 지원하지 않습니다.
- 벽 교차부가 여러 사각형으로 나뉘어 생성될 수 있습니다(시각적으로는 문제없음).
